Jak zasilić graf?

Graf zależności kodu buduje zewnętrzny ekstraktor graphify (tree-sitter AST, 36 języków). Ekstrakcja jest w pełni offline - kod nie opuszcza Twojej maszyny ani runnera CI. Monolynx tylko przyjmuje, przechowuje i serwuje graf. Synchronizacja jest opcjonalna per projekt - jej brak niczego nie psuje, graf po prostu pozostaje pusty lub nieaktualny.

1. Zainstaluj graphify (jednorazowo)

Na swojej maszynie lub na runnerze CI (gitlab-runner, self-hosted agent) - to odpowiedzialność właściciela projektu, step CI graphify tylko używa, nigdy nie instaluje. Uwaga: pakiet PyPI nazywa się graphifyy (podwójne „y"), komenda to graphify.

macOS / Linux

uv tool install graphifyy   # albo: pipx install graphifyy

Windows (PowerShell) - po instalacji zrestartuj terminal (PATH)

uv tool install graphifyy   # albo: pipx install graphifyy

2. Wygeneruj token API

Przejdź do Profil → Tokeny API i wygeneruj token (prefiks osk_). Slug tego projektu: {{ project.slug }}.

3. Wygeneruj skrypt synchronizacji

W Claude Code uruchom w katalogu swojego projektu skill /monolynx:create-graph-ci-script - wykryje system CI (GitLab / GitHub Actions / Bitbucket / Jenkins), wygeneruje .graphifyignore, cicd/sync_graph.py i step CI. Do jednorazowej, prowadzonej za rękę synchronizacji lokalnej służy skill /monolynx:graph-sync.

4. Synchronizacja lokalna

graphify update .
MONOLYNX_URL=https://monolynx.com \
MONOLYNX_GRAPH_TOKEN=osk_xxx \
MONOLYNX_PROJECT_SLUG={{ project.slug }} \
python cicd/sync_graph.py --dry-run   # najpierw dry-run, potem bez flagi

5. Synchronizacja w CI (po merge do main)

Step jest non-blocking: gdy graphify nie jest zainstalowane na runnerze, kończy się komunikatem i build projektu przechodzi dalej. Zmienne do ustawienia w CI: MONOLYNX_URL, MONOLYNX_GRAPH_TOKEN, MONOLYNX_PROJECT_SLUG.

GitLab CI (.gitlab-ci.yml)

sync-graph:
  stage: deploy
  allow_failure: true
  script:
    - command -v graphify || { echo "graphify nie zainstalowane na runnerze"; exit 0; }
    - graphify update .
    - python cicd/sync_graph.py
  rules:
    - if: $CI_COMMIT_BRANCH == "main"

GitHub Actions (.github/workflows/sync-graph.yml)

jobs:
  sync-graph:
    runs-on: self-hosted
    continue-on-error: true
    steps:
      - uses: actions/checkout@v4
      - run: command -v graphify || { echo "graphify nie zainstalowane"; exit 0; }
      - run: graphify update .
      - run: python cicd/sync_graph.py

Alternatywa: ręczne budowanie grafu

Dla przypadków niestandardowych graf można budować ręcznie - formularzami w tym module (Dodaj node / Dodaj krawędź) albo narzędziami MCP: create_graph_node, bulk_create_graph_nodes, bulk_create_graph_edges, replace_graph.
