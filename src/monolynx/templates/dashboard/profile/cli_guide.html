Podłącz CLI

Zaloguj terminalowego klienta monolynx do swojego konta w Monolynx

1

Zainstaluj CLI

Instrukcja instalacji jest w README paczki (paczka jest też na PyPI).

2

Zaloguj się

Komenda otwiera przeglądarkę i loguje przez OAuth 2.1, bez wklejania tokenu: 

monolynx auth login

Domyślny adres to https://monolynx.com. Dla innej instancji podaj jej adres: 

monolynx auth login --endpoint {{ app_url | e }}

Z --no-browser CLI nie otwiera przeglądarki, tylko wypisuje adres autoryzacji na stderr. Otwórz go w przeglądarce na tej samej maszynie, na której działa CLI: po zgodzie przeglądarka wraca na 127.0.0.1, gdzie czeka CLI. 

monolynx auth login --no-browser

Przez SSH bez przekierowania portów ten adres nie zadziała. Zaloguj się wtedy tokenem API z monolynx auth login --token <token> (krok 3).

3

CI i środowiska bez przeglądarki

Wygeneruj token na stronie Tokeny API. Możesz go zapisać w profilu: 

monolynx auth login --token <token>

Lepiej ustaw zmienne środowiskowe, wtedy token nie trafi do historii powłoki: 

export MONOLYNX_TOKEN=<token>
export MONOLYNX_ENDPOINT={{ app_url | e }}

MONOLYNX_TOKEN ma pierwszeństwo przed tokenem zapisanym w profilu i nie jest odświeżany.

4

Sprawdź logowanie

monolynx auth whoami

Uzupełnianie poleceń w powłoce: monolynx completion bash|zsh|fish (dla aliasu mnx osobno: mnx completion <powłoka>). Szczegóły w README paczki.
