- Test nowego kodu wykonuje jego ścieżkę wykonania; asercja na obecność literału w pliku źródłowym dokumentuje kształt pliku, nie chroni zachowania (MON-197: dwa testy greppujące `"BASE_BRANCH"` w `sprint_run_tick.py` przeszłyby, gdyby funkcja zawsze zwracała `""`). Gdy dopisanie testu zachowania wymaga pliku spoza przydziału (rozszerzenie fixture'a fakebin) - zgłoś `STOP:`, nie rozstrzygaj sam na korzyść testu tekstowego.
